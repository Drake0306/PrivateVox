# PrivateVox 0.5.0 alpha 1

Fourth alpha. This one is about how dictating feels while you do it: you see the words as they come, a tapped dictation ends itself when you stop talking, a spoken "new line" or "cancel" does what it says, Mail opens in Email mode by itself, and there is a soft click when recording starts and stops. Everything from 0.4.0 (host mode, dictionary, languages, kept audio) is still here, with the small leftovers from the reviews cleaned up.

**macOS on Apple Silicon** is the platform this was built and tested on. **Windows** and **Linux** builds come from the automated build and have not been run by a person yet.

## What is new
- **Live preview**: partial text on a second line of the pill while you speak. Settings → Dictation: Auto (on with a host or 16 GB+), On, Off.
- **Auto-stop** in toggle mode after 2 s of silence (change it or set Never).
- **Spoken commands** at the end of a dictation: "new line", "new paragraph", "delete that", "undo", "cancel", "never mind".
- **Modes per app**: Settings → Modes per app.
- **Sound cues** and a pill flash on start, stop and "nothing heard".

## Install
Same as 0.4.0: `PrivateVox_0.5.0_aarch64.dmg` on macOS (unsigned: right-click → Open the first time, or `xattr -d com.apple.quarantine /Applications/PrivateVox.app`), `PrivateVox_0.5.0_x64-setup.exe` or the `.msi` on Windows (SmartScreen: More info → Run anyway), the AppImage, `.deb` or `.rpm` on Linux. Settings and history are kept across upgrades.

## Known limitations
- The pill window is taller now (room for the preview line), so it sits a little higher than in 0.4.0, and a position you dragged to the very edge of the screen may snap back to the default once. Drag it again.
- Builds are not code-signed. Windows and Linux are untested by a person; the Mac-to-PC path has been tested with one Mac playing both roles.
- The live preview needs the model to be free: on an 8 GB Mac doing its own decoding it stays off unless you switch it on.
