# PrivateVox 0.3.0 alpha 1

Second alpha. New in this one: the text you dictate is cleaned up by a small language model before it is pasted, running on your own machine or on another machine on your network, and switching over on its own when one of them is not there. Everything from 0.2.0 (local Whisper dictation, three models, memory strip, history) is still here.

**macOS on Apple Silicon** is the platform this was built and tested on. **Windows** and **Linux** builds come from the automated build and have not been run by a person yet; please report what happens.

## What is new

- **Polish modes.** Clean (default), Email, Bullets, Code and Ask go through the LLM; Raw and Translate to English do not. Pick the mode in the panel header or the menu bar. Prompts are editable under Settings → Polish, with a reset.
- **Local first, LAN second.** Ollama, LM Studio or llama.cpp on this machine are found automatically. Add your PC by `ip:port` under Settings → Polish and it is used whenever it is reachable, with automatic fallback to the local model and back again. If nothing answers, the raw transcript is pasted and the row is marked *unpolished*.
- **Fast when warm.** The model is loaded when you press the key and unloaded on the same idle timer as Whisper. Turning polish off, or switching endpoint or model, unloads what is no longer needed, and the memory strip shows it.
- **Re-polish from history.** Any row can be run again with another mode; the Raw button shows Whisper's original.
- **Filler words removed** ("uh", "hmm", and "um" when the language is English) before saving and before the LLM. Toggle under Settings → Polish.
- **Memory strip** on macOS now shows Activity Monitor's "Memory Used", refreshes every 3 s, and counts a resident local LLM once.
- Fixes: "Paste again" hides the panel first so the text lands in the app you came from; the pill's level bars only show while listening.

## Install

### macOS (Apple Silicon, macOS 12 or newer)
1. Download `PrivateVox_0.3.0_aarch64.dmg`, open it, drag PrivateVox to Applications (replace the old one).
2. The build is not signed with an Apple Developer certificate. On first launch macOS will refuse to open it. Right-click the app → Open → Open, or run once in Terminal:
   `xattr -d com.apple.quarantine /Applications/PrivateVox.app`
3. Permissions are granted from the panel's **Setup** tab: Microphone, Accessibility (to paste), Input Monitoring (for the hold key). After granting Accessibility or Input Monitoring, quit from the menu bar and start again.
4. For polish on this Mac: install [Ollama](https://ollama.com) and run `ollama pull qwen2.5:3b`. The Setup tab shows "Polish LLM: Ollama ready" when it is found.
5. Hold **Right Option**, speak, release.

### Windows (x64, Windows 10/11, a Vulkan-capable GPU)
1. Download `PrivateVox_0.3.0_x64-setup.exe` (per-user installer, no admin rights) or `PrivateVox_0.3.0_x64_en-US.msi`. SmartScreen will warn because the build is unsigned: "More info" → "Run anyway".
2. Hold **Right Alt** to talk, or tap **Ctrl+Shift+Space** to toggle.
3. For polish: LM Studio with "Serve on local network" on, or Ollama; the app finds either on this machine. To share the PC's model with a Mac, add the PC's `ip:port` on the Mac.

### Linux (x64, X11)
1. Download `PrivateVox_0.3.0_amd64.AppImage` (make it executable), the `.deb` (Debian/Ubuntu) or the `.rpm` (Fedora/openSUSE).
2. Needs a Vulkan-capable GPU and driver, PulseAudio or PipeWire, and X11 for the hold key. Wayland is not supported in this alpha.

## Upgrading from 0.2.0
Settings and history are kept. The history database is migrated to schema v2 on first launch (a `polish_status` column); 0.2.0 can still open it if you go back.

## Known limitations
- Builds are not code-signed. Windows and Linux are untested by a person.
- The LAN path has been tested against a fake server, not yet against a real second machine.
- If you turn polish on and never dictate, the model stays loaded until you turn polish off or quit.
- Only the first spoken language is used; no personal dictionary yet; no audio is kept. Those are next.
