# PrivateVox 0.6.0 alpha 1

Fifth alpha. This one finishes the list from the design document and takes the first real pass on Windows. New: a copy-only dictation key, launch at login, a Model menu in the menu bar, history filters and Clear all, a microphone test, a paste method per app, a higher-precision turbo model on bigger machines, crash reports, a numbered first-run walkthrough, a microphone that stays warm between dictations, and tokens kept in the OS keychain instead of a JSON file.

**macOS on Apple Silicon** remains the platform the app has been used on day to day. **Windows** builds with whisper.cpp's Vulkan backend (any recent AMD, NVIDIA or Intel GPU) and all test suites pass on a Windows PC with an AMD card; the hold key and paste there are the next thing to be checked by a person. **Linux** builds come from the automated build and have not been run by a person.

## What is new
- **Copy-only key** (Ctrl+Shift+Alt+Space): the text goes to the clipboard, nothing is pasted, undo is left alone.
- **Menu bar**: Launch at login, Show pill, a Model submenu, Load model now.
- **History**: filter by app and by mode together with the search; Clear all… with an inline confirm (removes kept clips too).
- **Microphone test** in Settings and in Setup, with a level meter.
- **Paste method per app**: Type the text for terminals and remote desktops. Changing the Paste method setting now applies to the next paste.
- **Models**: `large-v3-turbo-q8` (874 MB) on machines with 12 GB or more.
- **Crash report** on any panic, with Show report in Setup.
- **Setup walkthrough**: numbered steps with a state each; the macOS grants only appear on macOS.
- **Warm microphone**: open for 20 s after a dictation (Settings, 0 to close at once).
- **Keychain**: host, remote and endpoint tokens live in the macOS Keychain or the Windows Credential Manager. Existing tokens move there on the first save.
- **Windows**: the engine worker now exits when the app dies; Benchmark works (clip synthesised with Windows Speech).
- Live preview is on by default for new installs; the Settings tab leads with Dictation behaviour.

## Install
`PrivateVox_0.6.0_aarch64.dmg` on macOS (unsigned: right-click → Open the first time, or `xattr -d com.apple.quarantine /Applications/PrivateVox.app`), `PrivateVox_0.6.0_x64-setup.exe` or the `.msi` on Windows (SmartScreen: More info → Run anyway), the AppImage, `.deb` or `.rpm` on Linux. Settings and history are kept across upgrades. From this release the macOS dmg is built by the same automated workflow as the other installers.

## Known limitations
- Builds are not code-signed. On macOS a debug build asks for keychain access after every rebuild; the bundled app is asked once.
- The microphone indicator stays on for the warm window after a dictation (20 s by default); set it to 0 in Settings if that bothers you.
- Linux keeps tokens in `settings.json` (no keychain wired there yet) and has no benchmark clip generator.
- Windows: the hold key, paste and host mode have not yet been exercised by a person; the unit and integration suites are green.
