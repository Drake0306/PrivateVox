# LVW — verified API reference (Rust + Tauri 2)

Compiled 2026-10-28 by a research pass over docs.rs, crates.io and v2.tauri.app. "Pin" versions are the newest stable released on or before 2026-10-14. Items the researcher could not verify are listed at the end.

## 1. Tauri 2 core

- **Pin:** `tauri = "2.12.4"`, `tauri-build = "2.7.3"`, npm `@tauri-apps/api` 2.12.4. Rust >= 1.90. Ignore 3.0.0-alpha.
- **Cargo features:** `tray-icon`, `image-png`, `image-ico`, `macos-private-api`, `devtools`, `protocol-asset`, `unstable`.
- **`macOSPrivateApi`**: key `app.macOSPrivateApi` (bool). No-op in Tauri 2.12.1+ (always enabled). Harmless to set `true`; tauri-nspanel 2.1 enables the `macos-private-api` cargo feature anyway.
- **tauri.conf.json WindowConfig** (type / default): `label`, `decorations` bool/true, `transparent` bool/false, `alwaysOnTop` bool/false, `skipTaskbar` bool/false, `visibleOnAllWorkspaces` bool/false, `focus` bool/true, `focusable` bool/true, `acceptFirstMouse` bool/false, `resizable` bool/true, `shadow` bool/true, `titleBarStyle` "Visible"|"Transparent"|"Overlay", `hiddenTitle` bool, `visible` bool/true, `width`/`height` f64 800/600, `x`/`y` f64|null, `closable`/`minimizable`/`maximizable` bool/true, `windowEffects`.
- **`WebviewWindowBuilder`**: `new<L: Into<String>>(manager: &'a M, label: L, url: WebviewUrl) -> Self`; `decorations(bool)`, `transparent(bool)`, `always_on_top(bool)`, `skip_taskbar(bool)`, `visible_on_all_workspaces(bool)`, `focused(bool)`, `focusable(bool)`, `accept_first_mouse(bool)`, `resizable(bool)`, `shadow(bool)`, `visible(bool)`, `position(x: f64, y: f64)`, `inner_size(w: f64, h: f64)`, `title_bar_style(TitleBarStyle)` (macos), `hidden_title(bool)` (macos), `content_protected(bool)`, `background_color(Color)`, `initialization_script(impl Into<String>)`, `devtools(bool)`, `build(self) -> Result<WebviewWindow<R>>`. All `self -> Self`.
- **`WebviewWindow`** runtime: `set_always_on_top(bool)`, `set_visible_on_all_workspaces(bool)`, `set_focusable(bool)`, `set_position(impl Into<Position>)`, `outer_position()`, `current_monitor()`, `primary_monitor()`, `monitor_from_point(x, y)`, `set_ignore_cursor_events(bool)`, `start_dragging()`, `ns_window() -> Result<*mut c_void>` (macOS), `hwnd() -> Result<HWND>` (Windows).
- **Drag from HTML:** `<div data-tauri-drag-region>` with `decorations: false`. Applies only to the element it is on (children need it too). Permission `core:window:allow-start-dragging` in `src-tauri/capabilities/default.json` (`"windows": ["pill"]`, `"permissions": ["core:window:default", "core:window:allow-start-dragging"]`). Manual alternative: `getCurrentWindow().startDragging()` on mousedown.
- **Events Rust -> JS:** `tauri::Emitter` trait (AppHandle, App, Window, WebviewWindow, Webview): `fn emit<S: Serialize + Clone>(&self, event: &str, payload: S) -> Result<()>`; `emit_to<I: Into<EventTarget>, S>(&self, target: I, event: &str, payload: S)`; `emit_filter`; `emit_str(&self, event: &str, payload: String)`. Payloads are JSON (use `tauri::ipc::Channel<T>` + `on_event.send(..)` for streams). JS: `import { listen, once } from '@tauri-apps/api/event'; const unlisten = await listen<T>('name', (e) => e.payload)`.
- **Plain JS, no bundler:** `app.withGlobalTauri: true`; `window.__TAURI__.{app, core, dpi, event, image, menu, mocks, path, tray, webview, webviewWindow, window}`. So `window.__TAURI__.core.invoke('cmd', {args})`, `window.__TAURI__.event.listen(...)`, `window.__TAURI__.window.getCurrentWindow()`.
- **Commands:** `#[tauri::command] async fn x(app: AppHandle, state: State<'_, T>, window: WebviewWindow) -> Result<T, String>`; `.invoke_handler(tauri::generate_handler![..])`; JS arg keys camelCase unless `#[tauri::command(rename_all = "snake_case")]`.
- **Run loop:** `pub fn run<F: FnMut(&AppHandle<R>, RunEvent) + 'static>(self, callback: F)` (never returns); `pub fn run_return<F>(self, callback: F) -> i32` (returns; use when cleanup must run after the loop). `RunEvent` (`#[non_exhaustive]`): `Exit`, `ExitRequested { code: Option<i32>, api: ExitRequestApi }` (`code` None for user-initiated), `WindowEvent { label, event }`, `WebviewEvent { label, event }`, `Ready`, `Resumed`, `MainEventsCleared`, `Opened { urls }`, `MenuEvent(MenuEvent)`, `TrayIconEvent(TrayIconEvent)` (feature `tray-icon`), `Reopen { has_visible_windows: bool }` (macOS dock click). `ExitRequestApi::prevent_exit(&self)` keeps the app alive when the last window closes.

## 2. tauri-nspanel

- **Pin:** `tauri-nspanel = "2.1.1"` (crates.io) or `{ git = "https://github.com/ahkohd/tauri-nspanel", branch = "v2.1" }`. objc2 0.6 / objc2-app-kit 0.3; requires tauri feature `macos-private-api`. Do not use legacy branch `v2`.
- **What it gives:** an `NSPanel` subclass of the Tauri window with `NSWindowStyleMask::NonactivatingPanel`, so showing/clicking the pill does not activate the app or steal focus from the target app. Pair with `app.set_activation_policy(ActivationPolicy::Accessory)` and `PanelBuilder::no_activate(true)`.
- **Init:** `tauri::Builder::default().plugin(tauri_nspanel::init())`; `use tauri_nspanel::ManagerExt;` -> `app.get_webview_panel("pill") -> Result<PanelHandle<R>, Error>`, `remove_webview_panel(label)`.
- **Convert:** `use tauri_nspanel::WebviewWindowExt;` `fn to_panel<P: FromWindow<R> + 'static>(&self) -> tauri::Result<PanelHandle<R>>` where `PanelHandle<R> = Arc<dyn Panel<R>>`. Define the class: `tauri_panel! { panel!(PillPanel { config: { can_become_key_window: false, is_floating_panel: true, becomes_key_only_if_needed: true, hides_on_deactivate: false } }) }` then `window.to_panel::<PillPanel>()?`. Or build directly: `PanelBuilder::<_, PillPanel>::new(&app_handle, "pill").url(WebviewUrl::App("index.html".into())).level(PanelLevel::Floating).floating(true).add_style_mask(StyleMask::empty().nonactivating_panel()).collection_behavior(CollectionBehavior::new().can_join_all_spaces().full_screen_auxiliary()).no_activate(true).transparent(true).with_window(|wb| wb.decorations(false).transparent(true).resizable(false).skip_taskbar(true)).build()`.
- **`Panel<R>` trait:** `show()` (orderFrontRegardless), `hide()`, `show_and_make_key()`, `order_front_regardless()`, `make_key_window()`, `is_visible()`, `set_level(i64)`, `set_floating_panel(bool)`, `set_becomes_key_only_if_needed(bool)`, `set_hides_on_deactivate(bool)`, `set_style_mask(NSWindowStyleMask) -> Result<(), StyleMaskError>`, `add_style_mask(..)` (preferred), `set_collection_behavior(NSWindowCollectionBehavior)`, `set_movable_by_window_background(bool)`, `set_ignores_mouse_events(bool)`, `set_has_shadow(bool)`, `set_opaque(bool)`, `set_alpha_value(f64)`, `set_content_size(f64, f64)`, `set_corner_radius(f64)`, `set_transparent(bool)`, `set_released_when_closed(bool)` (keep false), `set_event_handler(Option<&ProtocolObject<dyn NSWindowDelegate>>)`, `to_window()`, `as_panel() -> &NSPanel`, `content_view()`.
- **Constants (objc2-app-kit 0.3.2):** `NSWindowStyleMask::NonactivatingPanel`, `NSWindowCollectionBehavior::CanJoinAllSpaces | ::FullScreenAuxiliary | ::Stationary | ::IgnoresCycle`. Helpers: `StyleMask::empty().nonactivating_panel().value()`, `CollectionBehavior::new().can_join_all_spaces().full_screen_auxiliary().value()`, `PanelLevel::{Normal, Floating, ModalPanel, Utility, Status, PopUpMenu, ScreenSaver, Custom(i32)}` (Floating = 4, Status = 25).

## 4. Global shortcuts

- **Pin:** `tauri-plugin-global-shortcut = "2.4.1"` (wraps `global-hotkey 0.8`). Permissions: `global-shortcut:allow-register`, `allow-unregister`, `allow-unregister-all`, `allow-is-registered`.
- `Builder::new().with_handler(|app: &AppHandle<R>, shortcut: &Shortcut, event: ShortcutEvent| ..).build()`; `pub struct ShortcutEvent { pub id: u32, pub state: ShortcutState }`; **`pub enum ShortcutState { Pressed, Released }` — both exist.**
- `use tauri_plugin_global_shortcut::GlobalShortcutExt;` `app.global_shortcut()` -> `register<S: TryInto<ShortcutWrapper>>(shortcut) -> Result<()>`, `on_shortcut(shortcut, handler)`, `unregister`, `unregister_all()`, `is_registered(shortcut) -> bool`. `Shortcut::new(Some(Modifiers::ALT), Code::Space)`; `"Alt+Space".parse::<Shortcut>()`.
- **Lone modifier not possible** (`HotKey::new` requires a `Code`; macOS Carbon path errors `FailedToRegister("Unknown scancode for AltRight")`). tauri-apps/global-hotkey#159.
- **`rdev`:** crates.io 0.5.3 is stale (2023). Handy: `rdev = { git = "https://github.com/rustdesk-org/rdev" }` (0.5.0-2, last commit 2026-10-06). Handy's shortcut code today uses `handy-keys = "0.3.4"` (modifier-only combos) plus `tauri-plugin-global-shortcut`. API: `pub fn listen<T: FnMut(Event) + 'static>(callback: T) -> Result<(), ListenError>` (blocks; own thread). `EventType::{KeyPress(Key), KeyRelease(Key), ButtonPress, ButtonRelease, MouseMove{x,y}, Wheel{delta_x,delta_y}}`. Fork `Event { time, unicode: Option<UnicodeInfo>, event_type, platform_code: u32, position_code: u32, usb_hid: u32, extra_data: i64 }`. **Right Option on macOS = `Key::AltGr`** (kVK_RightOption 61); left Option = `Key::Alt` (58); `Key::MetaLeft` 55, `Key::MetaRight` 54, `Key::Function` 63, `Key::Unknown(u32)`. Fork's `listen` attaches the CGEventTap to `CFRunLoopGetMain()` then `CFRunLoopRun()` on the calling thread; `set_is_main_thread(bool)`; env `KEYBOARD_ONLY=1`.
- **macOS permission:** listen-only `CGEventTap` on keyboard events needs **Input Monitoring** (`CGPreflightListenEventAccess`/`CGRequestListenEventAccess`); Accessibility also satisfies it. Without it the callback is silently never called. Plan for both prompts.

## 5. Audio capture

- **Pin:** `cpal = "0.18.2"`. Breaking vs 0.16: `SampleRate` is `pub type SampleRate = u32`; unified `cpal::Error` with `ErrorKind` (`StreamConfigNotSupported` -> `ErrorKind::UnsupportedConfig`); `build_input_stream` takes `StreamConfig` by value; streams no longer auto-start; `Device::name()` deprecated -> `description()?.name()` / `id()`.
- `cpal::default_host()`; `HostTrait::default_input_device(&self) -> Option<Device>`, `input_devices()`; `DeviceTrait::default_input_config(&self) -> Result<SupportedStreamConfig, Error>`, `supported_input_configs(&self) -> Result<impl Iterator<Item = SupportedStreamConfigRange>, Error>` with `channels()`, `min_sample_rate()`, `max_sample_rate()`, `sample_format()`, `contains_rate(u32)`, `with_sample_rate(u32)` (panics if out of range; `try_with_sample_rate` exists), `.config() -> StreamConfig`.
- `fn build_input_stream<T, D, E>(&self, config: StreamConfig, data_callback: D, error_callback: E, timeout: Option<Duration>) -> Result<Stream, Error> where T: SizedSample, D: FnMut(&[T], &InputCallbackInfo) + Send + 'static, E: FnMut(Error) + Send + 'static`. `pub struct StreamConfig { pub channels: u16, pub sample_rate: u32, pub buffer_size: BufferSize }` (Copy); `BufferSize::{Default, Fixed(u32)}`; `StreamTrait::play(&self) -> Result<(), Error>`, `pause()`. macOS `Stream` is `Send` since 0.17.
- **16 kHz on CoreAudio:** cpal sets the device's physical format; if 16000 is not available -> `Err(ErrorKind::UnsupportedConfig)`; if it is, it changes the device's nominal rate system-wide. Capture at the default config (48 kHz typical) and resample.
- **Pin:** `rubato = "5.0.1"`. API differs from 0.16: `SincFixedIn`/`FftFixedIn`/`FastFixedIn` are gone. Types `Async<T>` and `Fft<T>`; I/O via `audioadapter` (`rubato::audioadapter_buffers::direct::SequentialSliceOfVecs`, `InterleavedSlice`). `Fft::<f32>::new(sample_rate_input: usize, sample_rate_output: usize, chunk_size: usize, nbr_channels: usize, fixed: FixedSync) -> Result<Self, ResamplerConstructionError>` (feature `fft_resampler`, default) — recommended for 48k->16k with `FixedSync::Input`; `Async::<f32>::new_sinc(resample_ratio: f64, max_resample_ratio_relative: f64, parameters: &SincInterpolationParameters, chunk_size: usize, nbr_channels: usize, fixed: FixedAsync)`; `Async::new_poly(ratio, max_rel, PolynomialDegree, chunk_size, channels, FixedAsync)` (cheap, voice). `Resampler<T>` trait: `process_into_buffer(&mut self, &dyn Adapter<T>, &mut dyn AdapterMut<T>, Option<&Indexing>) -> ResampleResult<(usize, usize)>`, `process(..) -> ResampleResult<InterleavedOwned<T>>`, `process_all(..)`, `input_frames_next()`, `output_frames_max()`, `output_delay()`, `reset()`.

## 9. Process plumbing

- **std:** `std::env::current_exe()`; `Command::new(exe).arg("--engine-worker").stdin(Stdio::piped()).stdout(Stdio::piped()).stderr(Stdio::inherit()).spawn()`; `Child { stdin, stdout, stderr }`, `kill()`, `wait()`, `try_wait()`, `id()`. Windows: `CommandExt::creation_flags(CREATE_NO_WINDOW)`; `AsRawHandle` for `Child`.
- **Parent-death detection in the worker (macOS):** (a) stdin read loop — `Ok(0)`/`UnexpectedEof` when the parent dies -> exit; (b) `libc`: `kqueue()`, `kevent(kq, &change, 1, &mut out, 1, null())` with `kevent { ident: getppid() as uintptr_t, filter: EVFILT_PROC, flags: EV_ADD | EV_ONESHOT, fflags: NOTE_EXIT, data: 0, udata: null_mut() }`; (c) poll `getppid() == 1`. Linux: `prctl(PR_SET_PDEATHSIG, SIGKILL)`. Use (a) primary, (b) belt-and-braces.
- **Windows job object** (`windows = "0.62.2"`, features `Win32_System_JobObjects`, `Win32_Foundation`, `Win32_System_Threading`, `Win32_Security`): `CreateJobObjectW(None, PCWSTR::null()) -> Result<HANDLE>`; `info.BasicLimitInformation.LimitFlags = JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`; `SetInformationJobObject(hjob, JobObjectExtendedLimitInformation, &info as *const _ as *const c_void, size_of::<JOBOBJECT_EXTENDED_LIMIT_INFORMATION>() as u32)`; `AssignProcessToJobObject(hjob, HANDLE(child.as_raw_handle() as _))`. Keep `hjob` alive. Safe wrapper: `win32job = "2.0.3"`.
- **Protocol:** `serde = "1.0.229"`, `serde_json = "1.0.154"`. Do not use bincode 3 (tombstone). **Recommend `postcard = "1.1.3"`** (`postcard::to_allocvec(&v)`, `postcard::from_bytes::<T>(&buf)`) for all frames. Framing: `w.write_all(&(len as u32).to_le_bytes())?; w.write_all(&buf)?; w.flush()?;` / `r.read_exact(&mut len4)?; r.read_exact(&mut buf)?`. Worker stderr inherited for logs; never log to stdout in the worker.

## 10. HTTP + discovery

- **`reqwest = { version = "0.13.5", features = ["json", "stream"] }`**: rustls is the default (feature `rustls`; no `rustls-tls` in 0.13). `Client::builder().timeout(Duration).connect_timeout(Duration).build()?`; `client.post(url).json(&body).send().await?.error_for_status()?.json::<T>().await?`; streaming `resp.bytes_stream()` + `futures_util::StreamExt` (`futures-util = "0.3.34"`).
