Phase 1 · Core dictation done

  • ✓
    Floating pillBottom-centre above the Dock, remembers where you drag it, never steals focus, states for idle / listening / loading / transcribing / pasted / error.
  • ✓
    HotkeysRight Option hold, Ctrl+Shift+Space toggle, hold-or-toggle, Ctrl+Shift+Z undo. Rebindable with a key recorder, applied without restart.
  • ✓
    Whisper engine in a worker processlarge-v3-turbo on Metal, crash and hang recovery, worker dies with the app, model preloads the moment you press the key.
  • ✓
    Capture and trimmingSilero VAD, "nothing heard" vs "mic is silent", 300 ms minimum, 5 min cap with countdown, overruns ignored.
  • ✓
    PasteClipboard + ⌘V with the old clipboard restored, disk backup across a crash, typing fallback, Accessibility re-checked per paste.
  • ✓
    History and settingsSQLite, search, idle unload timer you set in minutes, menu bar with pause-and-unload, first-run download with resume, clean exit on quit / SIGTERM / force-kill.

Phase 2 · Panel, models, memory, chunking done

  • ✓
    Three switchable modelsturbo (fast), large-v3 (accuracy), distil-large-v3 (English). Download, delete, benchmark, switch from the panel; switch waits for a recording to finish.
  • ✓
    GPU memory stripTotal, other apps, measured footprint of the selected model (703 MB for turbo on your M1), Recommended and Best-that-fits, red when it will not fit.
  • ✓
    Chunked decode while speakingLong dictations cut at pauses and decoded in order while you keep talking; scoring cost is constant per tick.
  • ✓
    History workbenchEdit in place, pin, paste again, raw view, export to Markdown or JSON in Downloads, word count.
  • ✓
    Undo last pasteSends ⌘Z only if the same app is still in front within 30 s; otherwise copies the text again.
  • ✓
    Panel to the mockupWide window, memory strip in the history, row layout, stats in the header.

Phase 3 · LLM polish and LAN next

  • Polish modesRaw, Clean (default), Email, Bullets, Code, Translate, Ask. Editable prompts with reset. Re-polish any history row with another mode.
  • Local LLM firstOllama on this Mac (qwen2.5:3b already pulled), OpenAI-compatible endpoints, keep-alive while Whisper is warm, warm-up request fired on key press, unloaded by the same idle timer.
  • LAN second, seamlessOrdered endpoint list, health checks every 10 s, automatic failover to the RX 9070 PC by IP and port and back again, "PC unreachable, polished locally" in the pill. Raw text pasted if nothing is up.
  • Polish LLM in the memory stripThe disabled "Polish LLM" selector comes alive; local models count against the budget, LAN ones count as 0 GB here.
  • Filler removal and clean-up without the LLMLanguage-gated filler words, so Raw mode reads clean too.

Phase 4 · Extras, Windows, release after

  • Personal dictionaryNames and jargon fed to Whisper as its prompt, fuzzy safety net when the prompt was not applied.
  • Spoken languagesMulti-select with the language identifier; translate mode. Today only the first language is used.
  • Keep audio clipsOff by default; replay next to the transcript; re-run with a bigger model.
  • Receipt-sequenced paste and secure-input detectionRestore the clipboard only after the target app actually read it; keep hotkeys alive next to password fields.
  • Share the engine on the LANThe PC serves Whisper to the Mac; discovery over mDNS; remote engine client behind the same trait.
  • Long-form document viewChunking exists; the multi-minute transcript as a document to copy or export does not yet.
  • Windows on the RX 9070Vulkan build, ROCm benchmark, Windows paste and hotkey specifics, installer. Runs when you are at the PC.
  • Open-source release passNotarised .dmg, CI on macOS and Windows runners, README for strangers, icon. Sponsor button already on.
  • Sixteen small deferred itemsFrom the two code reviews, listed in the ledgers under docs/superpowers/plans/: tray Resume item, casing of recorded keys, delete-while-downloading guard, and similar.
Suggested order for Phase 3: polish modes with local Ollama first (one afternoon of work, immediately useful), then the LAN endpoint list with failover, then the memory strip's LLM segment. Say "go" and it runs the same way as the first two plans: a written plan, tests first, a fresh review at the end.
