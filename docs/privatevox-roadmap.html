Status · 31 Oct 2026, night · v0.6.0-alpha.1 tagged, phase 6 built, Windows running

PrivateVox Roadmap

What the design promised, what is built, what is next. Six phases are built: it dictates, switches models, shows its memory, cleans up the text with a local or LAN LLM, hands the work to a PC on the LAN, previews, auto-stops, takes spoken commands, and has every setting and safety net the design listed. Phase 6 was finished on the Windows PC, where all three test suites are green with the Vulkan engine and Roy has now run the app by hand: it works. What is left is short, and listed first.

  • ✓

  • ✓
    A4 · Per-app default modesMail → Email, VS Code and Terminal → Code, Slack → Clean, from a small table in Settings. Half a session.
  • ✓
    A5 · Sound and visual cuesA soft click on start and stop, another on "Nothing heard", all off-able. Half a session.
  • ✓
    A3 · Spoken commands"new line", "delete that", "undo", "cancel" at the end of a dictation; editable list. One session; medium risk of false positives, limited to the last phrase.
  • ✓
    A6 · Deferred-minors cleanupThe twenty small items the three reviews left. One session.
  • ✓
    B1 · MLX engine spikeMeasured on 29 Oct: even on a 26 s clip, 35 % slower on short and medium clips. Not adopted; whisper.cpp stays the only engine.
  • B2 · Translate to any language via the LLMToday Translate only goes to English through Whisper. Half a session, if you need it.
  • C2 · Auto-update and signed buildsNeeds an Apple Developer account and a Windows certificate first; then one session with Tauri's updater.
  • C3 · Host mode extrasShared dictionary, client-driven host downloads, queue indicator. Decide after the first real PC-to-Mac run.

Not recommended: snippets, a stats page, streaming the LLM's answer, anything cloud.

Windows status running · 31 Oct

First real pass on a Windows PC with an AMD GPU (Vulkan, so any recent AMD, NVIDIA or Intel card). Roy ran the app by hand on the evening of 31 Oct and it works. Nothing is known to be broken.

  • ✓
    Runs on the PC, checked by handDictation, the pill and the panel, the GPU memory strip with the card named, the GPU / CPU switch and the Windows key names, all seen working by Roy on 31 Oct.
  • ✓
    Builds and passes every test on WindowsCore, engine and app suites green with the Vulkan engine. On Windows the Tauri CLI runs cargo through scripts/win-cargo.cmd (MSVC environment, Ninja, short target dir), so a plain cargo tauri dev works; other cargo commands go through pwsh scripts/win-cargo.ps1 …. Handled on the way: a CMAKE variable pointing at a folder ("Access is denied"), MSVC's long-path limit inside whisper.cpp's shader step, and dev sessions that left the app running (the wrapper now ends the app with the session and clears a leftover before a build).
  • ✓
    Fixed: the engine kept running after the app diedOn Windows a force-quit left the speech engine alive holding GPU memory. It now exits the moment the app is gone.
  • ✓
    Fixed: Benchmark had nothing to measureThe 30 s test clip was made with a Mac-only voice; Windows Speech makes it now.
  • ✓
    Fixed on both platformsPaste method changes needed a restart; the English-only model looked missing after a restart (wrong file name); an unplugged microphone could be silently reused.
  • ✓
    Windows-aware screensSetup skips the two Mac-only permissions and opens the Windows microphone settings page; tokens go to the Credential Manager; the Keys card names the hold keys for a PC keyboard with a Mac / Windows switch.
  • ✓
    Fixed: the memory strip showed RAM, no GPUIt now reads the card through DXGI ("AMD Radeon RX 9070 · 16 GB VRAM", what others hold) and has a GPU / CPU switch: CPU moves Whisper into system RAM and frees the GPU at once, and the bar follows.
  • !
    Still to try by handThis PC as the host for the Mac, and how fast the GPU transcribes (both in "What is left").
  • ✓
    Elevated-window warningA paste into an app running as administrator is refused by Windows; the pill warns while such a window is in front and the dictation ends as copied-only (built 31 Oct, night).
  • Quirk, not a bugWith a host offline the Test button says "did not answer in time" rather than "nothing answered": Windows takes two seconds to refuse a connection. The local fallback is the same.
