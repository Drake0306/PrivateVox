# Bundled models

- `ggml-silero-v5.1.2.bin`: Silero VAD v5.1.2 converted to ggml by the whisper.cpp project
  (https://huggingface.co/ggml-org/whisper-vad). Silero VAD is MIT licensed (c) Silero Team.
  Used for speech trimming before transcription. Whisper models themselves are downloaded on first run.
